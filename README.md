# Work Pix

Mi oficina en pixel art: cada skill y conector de mi equipo es un personaje con su propio sombrero. Toca a uno para ver su tarjeta y qué hace.

**Abrir la app:** https://rguerrerot4-boop.github.io/work-pix/

## Instalarla en el teléfono

- **iPhone (Safari):** abre el link, toca **Compartir** → **Añadir a pantalla de inicio**.
- **Android (Chrome):** abre el link, toca **⋮** → **Instalar app** o **Añadir a pantalla de inicio**.

Se abre a pantalla completa, con su propio ícono, y funciona aunque no tengas internet.

## Archivos

- `index.html` — la app completa (oficina, tarjetas, equipo).
- `crew.json` — la lista de personajes. Se actualiza sola todos los días.
- `manifest.webmanifest`, `sw.js`, `icons/` — lo que la hace instalable y usable sin conexión.
